# ADR-0006 — M4-a：差分回放矩阵——污点叠加的地基

日期：2026-10-26　　状态：已接受（契约定稿 2026-10-26；M4 开档首砖，
自 #16/M3-c 移入——issue #19）

简体中文版仅供参考，以英文版为准。English version:
[en/adr/0006-m4a-differential-replay-matrix.md](../../en/adr/0006-m4a-differential-replay-matrix.md)。

## 背景

M4 三支柱（2026-10-24）：覆盖率叠加、污点叠加、路径一致性校验（ADR-0005）。
差分回放矩阵为**污点支柱**开路：对 `.ktest` 的符号对象做受控扰动，重放 N
个变体，收集每站点**走向集合**。

两条既有裁决约束本层：

1. **阶梯模型**（ADR-0005）：M4 是离线独立工具——在回放环之外，不属于 DAP
   服务的运行时面。差分矩阵属引擎侧，消费一次性子进程重放链路。
2. **静态半边已在位**（ADR-0004）：`pathmark.classify` 陈述的是程序性质——
   *该站点可能是 fork*。纯静态断言说不出某站点**就是** input-dependent；
   扰动供给执行事实。两半互证，与多网交叉家法同构。

## 裁决

1. **扰动策略：位翻转基线**（用户裁，2026-10-26）。归因落到 bit 粒度，
   这正是「定位驱动字节」所需；大对象按尺寸分档做**确定性**降采样（同输入
   同计划——无随机）；超回放上限降级为显式「未分析」标记，绝不静默截断。
2. **「走向」v1 = 命中集差分**（用户裁，2026-10-26）。每变体记录命中的
   `(function, line)` 站点集加 exit code；命中成员跨变体变化的站点即
   **input-dependent**。ADR-0004 裁决 5（不记 taken/not-taken）维持；
   `server/` 保持零 diff。
3. **ktest 写侧准入**（用户裁，2026-10-26；显式翻 E1 裁决「纯读无 dump」）。
   `dump` 是纯函数 `KTest -> bytes`，照 ADR-0002 冻结布局，写单魔现行
   （`KTEST`；`BOUT\n` 保持只读 legacy），以往返钉 `parse(dump(k)) == k`。
   变体必须落成真 `.ktest` 文件——运行时只认真文件（`KTEST_FILE`）。
4. **置信由构造保证诚实。** 翻转是*必要非充分*：走向集合恒定的站点标
   「本观测内未见依赖」，绝不标「input-independent」；被 cap 截的分析如实
   标 capped。
5. **互证三臂**（静态 `pathmark` × 动态翻转）：静态 fork ∧ 翻转 ⇒ 强断言；
   静态 concrete ∧ 翻转 ⇒ 传播边界报警（运行时自检镜）；静态 fork ∧ 恒定 ⇒
   覆盖不足。任一站点恰落一臂。
6. **一变体一子进程。** 驱动壳照一子进程一会话家法（`_created` 守门）；
   进程代价远小于 LLDB load。M1+M3 形态回归不得破坏。
7. **验收**（issue #19）：get_sign 站点集 {11, 13}（`x==0` / `x<0`）且三
   基线（exit 0/1/255）全部可由翻转可达、驱动字节定位；two_objs mismatch
   分支由两对象各自翻转独立触发；M1+M3 回归绿。
8. **IR 精确化=可选参数**（用户裁，2026-10-26）。无 `.ll` 时矩阵纯动态、
   自成报；提供则启用裁决 5 的互证三臂。照 launch `ir` 参数家法：
   **缺席零增**。报告如实标互证是否在场。
9. **恒被求值站点如实标盲**（用户裁，2026-10-26）。命中集差分对每条路径
   都执行的站点（get_sign L11，首个 `if`）结构性失明——此类站点如实标
   「本观测内未见依赖」+覆盖不足臂；站点级判定不吸收程序级证据。验收读法
   随之修正：「三站点」=三出口（0/1/255）全可由翻转可达；fork 站点 L13
   标 input-dependent，L11 走盲区臂。

## 后果

- 污点叠加得到地基：站点 × 输入字节依赖可测；ptrfuzz 生态获得库级依赖
  （打包押后至需求实证，家法同款）。
- E1 冻结的纯读范围获得写半边与自带往返网；ADR-0002 字节布局从此写侧同盖。
- `pathmark` 得到首个运行时 oracle：传播边界报警是闭包边界的活证，
  不再只是测试夹具。
